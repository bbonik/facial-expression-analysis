# Facial Expression Analysis

[![CI](https://github.com/bbonik/facial-expression-analysis/actions/workflows/ci.yml/badge.svg)](https://github.com/bbonik/facial-expression-analysis/actions/workflows/ci.yml)
![Python](https://img.shields.io/badge/python-3.11%20%7C%203.12%20%7C%203.13-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Estimate **dimensional emotions** (arousal, valence, intensity) and a verbal label such as
*"Moderately happy"* from 68 facial landmarks, using interpretable **classical machine learning**.
The model is a 31 KB linear regressor that takes ~70 µs per face on a laptop CPU.

![example1](data/images/example.gif "example1")

> **v2 is in progress** on the `v2` branch: a full rewrite of the 2021 code with a bug-fixed and
> retrained model. The original code is tagged [`v1.0.0`](../../tree/v1.0.0).

## How it works

```
image ──dlib──▶ 68 landmarks ──Procrustes──▶ normalised shape ──linear frontalization──▶ frontal shape
      ──▶ 1275 pairwise distances (no jaw) ──PLS regression──▶ arousal, valence ──▶ circumplex label
```

1. **Landmarks:** dlib's HOG face detector and 68-point shape predictor.
2. **Shape normalisation:** translation, scale and in-plane rotation are removed (Procrustes).
3. **Frontalization:** a linear model maps the shape to its frontal-view estimate, removing
   head-pose effects ([Vonikakis & Winkler, ICIP 2020](https://stefan.winkler.site/Publications/icip2020a.pdf)).
4. **Geometric features:** Euclidean distances between all pairs of the 51 non-jaw landmarks,
   divided by a face scale estimated from expression-stable landmarks (nose and eye corners).
5. **Regression:** Partial Least Squares, trained on **MorphSet**: 83k face images (plus mirrored copies) of 337 people with
   dimensional labels generated by face morphing ([Vonikakis et al., ICIP 2021](https://arxiv.org/abs/2103.02854)).
6. **Label:** angle and radius in the valence-arousal plane are mapped to one of 24 emotion words
   from Russell's circumplex model, plus an intensity qualifier.

## Quick start

```bash
git clone https://github.com/bbonik/facial-expression-analysis.git
cd facial-expression-analysis
uv sync                                    # or: pip install -e ".[train]"
uv run fea predict data/images/kids.jpg -o outputs/
```

```text
data/images/kids.jpg: 2 face(s)
  [1] Extremely delighted      arousal=+0.584 valence=+0.515 intensity=0.779
  [2] Extremely pleased        arousal=+0.101 valence=+0.865 intensity=0.871
```

The dlib landmark model (~100 MB) is downloaded and cached on first use.

### Command line

| Command | Description |
|---|---|
| `fea predict IMG... [-o DIR] [--json]` | Analyse every face in one or more images |
| `fea webcam` | Live overlay with arousal-valence trail (q / Esc to quit) |
| `fea train [--components 31] [--subset no_jaw] [--scale stable]` | Retrain on MorphSet with a person-wise split |
| `fea evaluate [-m MODEL]` | Evaluate a model on held-out test persons |
| `fea benchmark IMG` | Per-stage latency |
| `fea download [--dataset]` | Pre-fetch the external assets |

### Python API

```python
from facial_expression_analysis import DlibLandmarkDetector, EmotionEstimator, load_image

estimator = EmotionEstimator()  # bundled model
faces = estimator.analyze_image(load_image("face.jpg"), DlibLandmarkDetector())
for face in faces:
    e = face.emotion
    print(e.label, e.arousal, e.valence, e.intensity)

# Or work directly with (n, 68, 2) landmark arrays, vectorised:
avi = estimator.predict(landmarks)  # (n, 3)
```

## Results

5-fold cross-validation grouped by **person**, so no person appears in both the training
and the test fold. PLS with 31 components. Concordance correlation coefficient (CCC, mean ± sd
over folds; higher is better):

| Features | Arousal | Valence | Intensity |
|---|---|---|---|
| 2021 template (see below) | 0.600 ± 0.020 | 0.795 ± 0.011 | 0.637 ± 0.013 |
| 51 non-jaw landmarks, subset scale | 0.620 ± 0.020 | 0.804 ± 0.011 | 0.656 ± 0.019 |
| **51 non-jaw landmarks, stable scale (default)** | **0.616 ± 0.019** | **0.806 ± 0.011** | **0.654 ± 0.019** |
| 49 IntraFace landmarks, stable scale | 0.618 ± 0.019 | 0.804 ± 0.012 | 0.655 ± 0.018 |
| all 68 landmarks, stable scale | 0.615 ± 0.020 | 0.804 ± 0.011 | 0.644 ± 0.018 |

Findings, from paired per-fold comparisons:

- **Feature template fix: +0.021 / +0.009 / +0.019 CCC, better in 5 of 5 folds.** The 2021 code
  was ported from a MATLAB system built on the 49-point IntraFace landmarks, which have no jaw
  points. Its feature template kept IntraFace-style *positions* (0–50) while indexing the
  68-point dlib array, so it used the jaw and dropped 17 of the 20 mouth landmarks.
- **Excluding the jaw helps:** adding it costs 0.011 intensity CCC.
- **Scale reference.** Expressions inflate scale estimates that include the mouth and eyebrows
  (surprise: +5.6%). The default normalises by the nose and eye corners instead (+0.4%), so
  each feature responds only to its own landmarks. This costs 0.005 arousal CCC: the
  inflation itself is a weak arousal cue.
- **Identity leakage.** MorphSet's `Subject` column identifies photo series, not people
  (RaFD gaze directions, KDEF sessions and FACES picture sets each got their own id). Grouping
  by subject instead of person overstates valence and intensity CCC by ~0.007 and halves the
  apparent fold-to-fold variance. See `facial_expression_analysis/data.py`.

Latency on an Apple M3 with a 640×426 image: dlib detection + landmarks takes 14.9 ms;
frontalization, features, regression and labelling together take 0.07 ms.

## Repository layout

```
src/facial_expression_analysis/
├── geometry.py          Procrustes normalisation (vectorised)
├── frontalization.py    Linear landmark frontalization
├── features.py          Pairwise-distance features
├── model.py             Portable linear model (.npz, no scikit-learn needed at inference)
├── pipeline.py          EmotionEstimator: landmarks/images → emotions
├── labels.py            Circumplex labels
├── landmarks/           Detector interface + dlib back-end
├── data.py              MorphSet loading, person ids, person-wise splitting
├── training.py          Training and evaluation
├── metrics.py           CCC, RMSE, MAE
├── cli.py, live.py      Command line and webcam demo
└── assets/              Bundled frontalization weights and emotion model (~180 KB)
tests/                   Unit, regression and equivalence tests against the 2021 implementation
notebooks/archive/       Original 2021 notebook
data/                    MorphSet (zipped) and sample images
```
